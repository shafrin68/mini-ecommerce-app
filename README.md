# Mini E-Commerce App

## About
A responsive Mini E-Commerce Web Application built using HTML, CSS, and JavaScript. Users can browse products, add items to the shopping cart, manage quantities, and view the total price.

## Features
- Displays 8 fictional products
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Automatically calculates subtotal and total amount
- Delivery fee calculation
- Saves cart items using LocalStorage
- Checkout preview without real payment
- Responsive design for mobile and desktop

## Technologies Used
- HTML
- CSS
- JavaScript
